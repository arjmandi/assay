Abstract

An agent that works for hours in a world it does not know has to keep what it learns somewhere. Assay keeps it outside the model and outside the harness: the agent names the parts of the world it cares about, writes a prediction over them before every action, and the harness grades every outcome against the real behavior inside the world. A fact enters the world model only through a prediction that held.

§ 01Get started

Use Assay in Claude Code.

Assay ships as a Claude Code plugin. Play ARC-AGI-3 with it, or bring your own world: Claude builds the pack that connects Assay to it, and you say what to achieve there.

01Install the plugin

Once, in any Claude Code session.

Claude Code
/plugin marketplace add arjmandi/assay
/plugin install assay@assay

Then pick a world.

The ARC-AGI-3 pack ships with the plugin. You need uv and an API key from arcprize.org.

01Save your ARC API key

Once, in your own terminal. It asks for the key without showing it, and only the harness reads the file, so the key reaches neither the agent nor the record.

Terminal
mkdir -p -m 700 ~/assay/tokens && (umask 077; printf 'ARC API key: '; read -rs k; echo; printf '%s\n' "$k" > ~/assay/tokens/arc_api_key)
02Attach the pack with a game

Any of the 25 public games, by its id. The first time, it builds the game's Python; then it starts the run, capped at 200 actions.

Claude Code
/assay:attach arc-agi-3 "win the game ft09"
03Play it, watch it, read the report

The published ft09 run won 6 of 6 levels in 82 actions, with 185 outcomes held and 5 missed.

Claude Code
/assay:run
/assay:watch
/assay:report

Files, a simulator or a game on your machine, a repository with tests, or a service with an MCP server or an HTTP API.

01Connect your world

Describe it, and what counts as done there. Claude builds the pack that connects Assay to it, tests it, and prints where it is.

02Say what to achieve

The run starts on your pack with your goal, and the owner token stays out of the agent's reach.

Claude Code

03Play it, watch it, read the report

The run ends when the world says so: the goal reached, the budget spent, or a stop the agent declares with its reason.

§ 02The problem

LLMs consume context, but context rots.

The agent runs for hours, across sessions, with a budget of actions and a context window as its only working memory. What it learns has to be written somewhere, and the choice of where decides three things: what happens when the context fills, when the session ends, and when the agent is wrong.

Assay is the fourth system in one research line.1 The first three documented their own failures, and the paper states them in the formal terms it later uses.

1 Sensi (arXiv:2603.17683) and ARG (arXiv:2608.04066) are published; arg-v2 is unpublished.

Failure mode 1

Referent grounding

A rule written in prose names something the model cannot reliably locate in the observation again, so the rule can never be checked and silently degrades to a belief.

Failure mode 2

Belief accounting

A theory that fits every observation made so far is treated as supported in regions no observation visited.

Forgetting across a long context makes both chronic. The prose that stood in for the referent and the evidence that stood in for the support are the first things a long context loses.

March 2026Sensi

Perception separated from action, a hand-written curriculum, a language-model judge deciding what was learned.

What brokeA wrong frame diff became a wrong fact; the judge scored it consistent. Ground truth never entered the pipeline.

August 2026ARG

A deterministic executive owned all belief. A rule was admitted only when a prediction registered before acting matched the observation by code.

What brokeZero level completions in 52 gated runs. Consistent-but-wrong theories pass when probes lack discriminating power; the closed vocabulary was a binding constraint.

August 2026 · unpublishedarg-v2

Open vocabulary, Python in a sandbox, a registry and adapter seam, verifier code hash-committed before action.

What brokeOver-generation: one run proposed 111 rules and left 105 untested. Forgetting between sessions. The referent problem, now instrumented and still unsolved.

This paperAssay

An outcome must name a registered state or a program, so every rule has a computed referent. The gate makes a graded outcome the only way a belief enters the record.

What changesThe support of a rule becomes a query over the record rather than a recollection.

§ 6.11One sentence, moved between layers

        
The OOLONG registry's goal text carried one strategy sentence: the corpus is a file in the run directory and should be read with the agent's own offline tools. Removing that sentence, and nothing else, produced the de-hinted arm. At the 1M-token rung the two arms scored within one question of each other and their cost moved by close to an order of magnitude. At 128K the sentence was worth 0.870 against 0.764, and without it the counting group of questions collapsed. A sentence at the registry layer changed cost and changed capability on one question class, with the kernel and the constitution untouched.
