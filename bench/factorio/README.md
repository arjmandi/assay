# Factorio benchmark

Planned benchmark; runs and results will be documented here. It will follow
the same shape as `bench/arcagi`: a world adapter exposing
`factory(root, config)`, pre-registered action registries, a PROTOCOL.md, and
a RESULTS.md.

Current status: **research phase**. `RESEARCH.md` is the source dossier —
what Factorio and the Factorio Learning Environment (FLE) are, published
results and top performers, the Prime Agent reward-hacking incident, cost
and duration estimates, the proposed ASSAY modeling (adapter/registry
options, channels, win conditions, anti-cheat), the staged rollout plan
(M0–M4), and the open questions the owner decides before a PROTOCOL.md is
written.
